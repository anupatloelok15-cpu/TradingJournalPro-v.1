SMC Trading Journal Pro

เว็บบันทึกและวิเคราะห์การเทรดส่วนตัว สำหรับ SMC / ICT Trading Journal

วิธีอัปโหลดขึ้นอินเทอร์เน็ตแบบง่ายที่สุด

วิธีที่ 1: Netlify
1. เข้า netlify.com
2. Login
3. เลือก Add new site
4. เลือก Deploy manually
5. ลากไฟล์ ZIP นี้ไปวาง
6. รอระบบ Deploy
7. จะได้ลิงก์เว็บทันที

วิธีที่ 2: Vercel
1. เข้า vercel.com
2. Login
3. Add New Project
4. Upload โฟลเดอร์นี้ หรือเชื่อม GitHub
5. Deploy

วิธีที่ 3: GitHub Pages
1. สร้าง Repository ใหม่
2. อัปโหลดไฟล์ index.html และโฟลเดอร์ assets
3. ไปที่ Settings > Pages
4. เลือก Branch main
5. Save แล้วรอลิงก์เว็บ

ไฟล์หลัก
- index.html = ตัวเว็บ
- assets/guide_smc_trading_journal.png = รูปคู่มือการใช้งาน

หมายเหตุ
ข้อมูล Trading Journal จะบันทึกอยู่ใน Browser ของผู้ใช้งานแต่ละคนผ่าน localStorage
ถ้าเพื่อนเปิดเว็บจากเครื่องตัวเอง ข้อมูลจะเป็นของเครื่องเพื่อน ไม่ปนกับของคุณ
